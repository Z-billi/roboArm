# 硬件与复现范围

以下清单依据当前固件、桌面控制程序和已有项目说明整理，不是已经完成采购及实机验收的整机 BOM。

| 项目 | 数量 | 说明 |
| --- | --- | --- |
| Arduino UNO | 1 | 固件目标 `arduino:avr:uno` |
| CNC Shield V3 | 1 | 使用 X/Y/Z，A 轴未启用 |
| A4988 驱动模块 | 3 | 每轴一块，限流按实际采样电阻和电机参数配置 |
| 步进电机 | 3 | 三轴控制；模型含 42 步进电机，实际型号、相电流与步距角需核对 |
| 0～180°位置舵机 | 2 | 信号接 D12、D13；实际机械行程需校准 |
| 电机直流电源 | 按负载配置 | 核对 Shield、驱动模块和电机规格；USB 不能代替电机电源 |
| 舵机稳压电源 | 按负载配置 | 按实际舵机额定电压及堵转电流选型，逻辑共地 |
| USB 数据线 | 1 | 同时用于固件上传和串口通信 |
| 机械结构及紧固件 | 以装配设计为准 | 见 `roboArm Model/`，尚无独立的标准件规格/数量表 |

接线引脚、限流、上电步骤、共享使能与舵机保持行为见 [项目 README](../README.md#1-接线和首次通电)。

## 机械复现仍需补充

- 装配体在 SolidWorks 中的完整引用核查及 Pack and Go 验证。
- 自包含的整机 STEP 导出（当前同名 STEP 文件引用缺失的外部 STEP 零件）。
- 标准件尺寸与数量、材料、公差、加工/打印参数及装配顺序。
- 电机、舵机、减速比和关节映射的实机确认。
- 行程、负载、制动、温升及运动精度的实测结果。

当前软件按 X/Y/Z 轴输出步进脉冲，不包含逆运动学、路径规划、限位或回零。不能仅凭模型名称推导可直接执行的关节角度或末端坐标。
