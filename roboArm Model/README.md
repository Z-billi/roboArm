# 机械臂建模文件

本目录保存机械臂已有的原生 SolidWorks 模型和 STEP 导出。请下载整个目录，保持文件名与相对位置，避免破坏装配体引用。

## 文件组成与打开方式

| 类型 | 数量 | 用途 |
| --- | ---: | --- |
| `.SLDPRT` | 22 | 原生零件，可在兼容 SolidWorks 中查看特征和修改尺寸 |
| `.SLDASM` | 3 | `装配体1.SLDASM`、`装配体2.SLDASM`、`夹爪.SLDASM` |
| `.STEP` | 4 | 现有中性格式导出，详见下方限制 |

STEP 头部标记导出工具为 **SolidWorks 2025**。建议使用兼容该版本的 SolidWorks 打开原生文件；尚未验证其他版本兼容性，也尚未确认两个编号装配体中哪个是最终整机版本。

打开装配体时让 SolidWorks 在本目录查找引用文件。如果提示缺件，先在本目录重新定位；不要忽略报错后将装配体当作完整整机使用。当前只完成文件清点，未完成 SolidWorks 中的装配重建、干涉或配合验证。

## STEP 导出的已知限制

`42步进电机.STEP`、`两侧传动齿轮.STEP`、`小齿轮帽.STEP` 包含实体几何记录。

**`总装配体.STEP` 是引用外部 STEP 文件的装配结构，不是自包含的整机实体文件。** 当前目录缺少以下被引用的文件：

- `两侧传动大齿轮.STEP`
- `中臂膀.STEP`
- `大臂.STEP`
- `大齿轮.STEP`
- `夹爪.STEP`
- `底座.STEP`
- `座体.STEP`
- `末端连接键.STEP`
- `轴承外圈.STEP`
- `连接三角.STEP`
- `连杆.STEP`
- `连杆2（2）.STEP`
- `连杆3.STEP`
- `连杆摆动块.STEP`

这些名称中的多数有对应原生零件，但不能通过改扩展名得到 STEP。需要在 SolidWorks 中检查完整装配后重新导出包含全部几何的 STEP，或补齐所有外部 STEP 文件。现有原件均保留发布，未把缺失的导出伪装为已完成。

完整文件大小、SHA-256 和外部引用清单见 [模型文件清单](../docs/MODEL_INVENTORY.md)。

## 发布处理与许可

- 22 个原生零件和 3 个装配体保持原始二进制内容。
- 4 个 STEP 仅将头部的个人邮箱作者字段改为 `Z-billi`，几何和装配数据段逐字节保持不变。
- SolidWorks 的 `~$` 文件是临时锁文件，不属于模型源文件，不纳入版本管理。
- 作者自有模型按仓库根目录的 [MIT 许可证](../LICENSE) 发布；第三方库或模型的既有权利仍归原权利人。

控制器引脚不等于机械关节定义；轴方向、传动比、限位和舵机端点需结合实际机构校准。整机标准件 BOM、加工参数和装配步骤尚待补充，见 [硬件说明](../docs/HARDWARE.md)。
